# Dataset

The intrusion detection experiments use the CIC-IDS2017 dataset.

Dataset used:
`Friday-WorkingHours-Afternoon-DDos.pcap_ISCX.csv`

Source:
Canadian Institute for Cybersecurity (CIC)

The original dataset is not included in this repository because of its large file size.

The dataset is used for research and experimental evaluation of the intrusion detection system.
